    Model details and limitations

    Research model—not a diagnosis. Results are generic model estimates, not patient measurements.

    Model: MoBL-ARMS Dynamic Upper Limb with — bodies, — muscles, — ligaments, and — authored meshes. The model supplies the anatomy and muscle paths; tube width is illustrative.

    Mirror view: reflects the rendered right-limb model for left-side visualization. It does not change the right-side coordinates or activation calculation and is not a separately validated left-arm model.

    Static posture: calculated for the exact displayed angles under model gravity, with no external hand load. Results are shown only after convergence, equilibrium, and reserve checks pass. Passive muscle-fiber force and real co-contraction are not represented.

    Reach8 movement: reads the authors’ CMC_results_states.sto directly. It is the only recorded movement currently included and is not an estimate for the slider posture.

    Interpretation: activation is a generic model state from 0–1. It is not measured effort, force, pain, damage, fatigue, diagnostic confidence, or a patient-specific result.

    Observation workflow: the Diagnosis tab records self-reported symptoms and movement observations and generates biomechanical hypotheses only. It cannot identify a painful tissue, rule out urgent conditions, or replace assessment by a qualified clinician.

    Movement screens: the default moderate set uses 18 progressive postures from a 39-position exact search; all 39 intact postures passed the model quality gates. Complete modeled loss of any single target group remained mechanically feasible throughout this moderate set because other muscles compensated, so it records movement difficulty but does not calculate a muscle signature. The separate seven-position advanced set was selected from 444 baseline-valid gravity-only postures for noiseless model separation only. It is extreme, has no independent error-correcting panel, is not clinically validated, and does not identify a painful or injured tissue.

    Force output: when a static posture passes every quality gate, activeActuatorForceN is a generic, pose-linearized active actuator estimate. It excludes passive muscle-fiber force and external hand loads and is not measured patient force. Shoulder joint reaction is not calculated.

    Model coverage: trapezius and serratus anterior are not independent muscle actuators in this model; scapular and clavicular motion follows authored coupling constraints. Resisted, supported, and assisted tests require measured external loads before model demand can be interpreted.

    Full-body preview: the separate MS-Human-700 viewer displays an Apache-2.0-licensed model in its authored default pose. It does not supply anatomy, motion, activation, or diagnostic results to this upper-limb workflow.
